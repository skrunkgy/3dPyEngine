# Basic 3D Graphics Engine

This is a simple engine for drawing 3d scenes and exploring them. It includes:
- A flycam
- Loading 3d models with textures
- Lighting!!!
- Billboards
- A HUD

This project uses:
- Pygame: Image stuff, input, window handling and other OS stuff
- Moderngl: Modern OpenGL binding for Python, also does small QoL stuff for implementations
- GLM: Math library :)
